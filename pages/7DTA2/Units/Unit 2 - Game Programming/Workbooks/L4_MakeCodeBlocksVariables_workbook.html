What We're Learning Today

Objective

Learning objective: Explore the MakeCode Arcade environment, explain what different categories of blocks do, and use variables to track values that change while a game runs.

Click each criterion when you can actually demonstrate it — not when you think you could.

🟢 Foundation

I can identify the main block categories, complete a guided tutorial, and explain what a variable is using the labelled box analogy.

🟡 Developing

I can explain what an "event" block does and why games are built around events, and create a variable with a starting value that changes correctly.

🟣 Extending

I can add an extra event-driven behaviour beyond the tutorial, and use two variables together to drive a win or lose condition.
