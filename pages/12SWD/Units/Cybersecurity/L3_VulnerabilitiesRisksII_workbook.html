🟣 Extending

Scenario — GreenLeaf Logistics: a contractor's system access was never deactivated after their contract ended in March. In April, that account was used, from an unrecognised location, to access the live customer database — the same database developers and testers normally connected to directly for day-to-day work — and export delivery details for around 40,000 customers. A later review found that the code change which had introduced the access loophole in the first place was merged after a single one-line review comment, two days before a product launch deadline.
