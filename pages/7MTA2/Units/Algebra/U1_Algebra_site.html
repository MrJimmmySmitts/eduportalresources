Algebra Revision

Learning objective To be able to solve one- and two-step equations using both the balance method and the flowchart method — and to explain which parts of algebra I still need to revise.
🟢 FoundationI can use the key words correctly, continue a pattern, substitute a number into an expression, and solve a one-step equation.
🟡 DevelopingI can write the rule for a pattern, solve two-step equations by both methods, and check my answer by substituting it back in.
🟣 ExtendingI can solve equations with brackets, negatives, or x on both sides, and turn a worded problem into an equation of my own.

Vocabulary

The Language of Algebra

Copy this onto your bound reference: The seven key words and the invisible-1 rule.

Every algebra question is written in a code. If you know the words, you can read the code.

WordWhat it means
Pronumeral (variable)A letter standing in for a number we don't know yet.
CoefficientThe number multiplying a pronumeral.
ConstantA term that is just a number — no letter attached.
TermA chunk separated by + or − signs.
ExpressionTerms joined by operations. No equals sign.
EquationTwo expressions joined by an equals sign.
Like termsTerms with exactly the same letter(s) and power.
Example: In 6x + 4y − 9 there are 3 terms. The coefficient of x is 6, the coefficient of y is 4, and −9 is the constant. Because there is no equals sign, this is an expression, not an equation.
Watch out: x on its own has a coefficient of 1, and −x has a coefficient of −1. The 1 is invisible but it is there.

Sequences

Patterns & Rules

Copy this onto your bound reference: The three-step method for finding a rule, and the worked example.

A pattern that goes up (or down) by the same amount every time has a rule of the form rule = (common difference) × n + (starting adjustment), where n is the term number (position), not the term itself.

Worked example — find the rule for 5, 8, 11, 14, …
  1. Find the common difference. 8 − 5 = 3. That 3 is the coefficient of n, so the rule starts as 3n.
  2. Test 3n against term 1. 3 × 1 = 3, but the real term is 5.
  3. Adjust. 3 is 2 short of 5, so add 2. Rule = 3n + 2.
  4. Check on a different term. Term 4: 3 × 4 + 2 = 14 ✔
Using the rule: once you have it, the 50th term needs no counting — substitute n = 50. And to find which term equals a value, set the rule equal to it and solve: 3n + 2 = 47 → n = 15, so it's the 15th term.
Decreasing patterns have a negative common difference: 20, 17, 14, … goes down by 3, so the rule is −3n + 23 (also written 23 − 3n).

Substitution

Copy this onto your bound reference: The worked example and all three traps.

Substitution means swapping each pronumeral for the number you've been given, then evaluating using the order of operations (BIDMAS).

Worked example — find 3x + 4 when x = 5
  1. Rewrite with the number in place of the letter, putting the hidden × back in: 3 × 5 + 4
  2. Multiplication before addition: 15 + 4
  3. = 19
The three things that catch people out:
  • 3x means 3 × x — never 3 next to 5 making 35.
  • x² means x × x, not x × 2. So if x = 4, x² = 16, not 8.
  • Brackets and fraction lines are done first, all the way across: (a + b) ÷ 2 with a = 7, b = 9 is 16 ÷ 2 = 8.

Balance & Flowchart

One-Step Equations

Copy this onto your bound reference: The inverse-operations table and one worked example of each method.

A one-step equation has had one thing done to the pronumeral. To solve it you undo that one thing. Both methods below do exactly that — pick whichever you find clearer, but be able to use one of them fluently.

Method 1 — Balance. An equation is a set of scales. Whatever you do to one side, you must do to the other, or it tips.
x + 6 = 13
− 6 from both sides
x + 6 − 6 = 13 − 6
x = 7
Method 2 — Flowchart. Draw what happened to x going forwards, then walk back through it doing the opposite.
x— +6 →13
7← −6 —13
Going back, every operation flips to its inverse.
OperationIts inverse
+ (add)− (subtract)
− (subtract)+ (add)
× (multiply)÷ (divide)
÷ (divide)× (multiply)
Always check. Substitute your answer back in: 7 + 6 = 13 ✔ If it doesn't work, the answer is wrong — and you found it yourself.

Two-Step Equations

Copy this onto your bound reference: The reverse-order rule and the side-by-side worked example.

A two-step equation has had two things done to the pronumeral. The rule that makes this easy: undo in the reverse order — last thing done is the first thing undone.

Worked example — solve 3x + 5 = 20
Balance method
3x + 5 = 20
− 5 from both sides
3x = 15
÷ 3 on both sides
x = 5
Flowchart method
x— ×3 →3x— +5 →20
5← ÷3 —15← −5 —20
Why undo the +5 first? Going forwards, x was multiplied then added to. Walking back out, you meet the addition first. Undoing the ×3 first would mean dividing the 5 as well — a very common mistake.
Brackets are different. In 2(x + 3) = 16 the bracket was built first, so the ×2 is the last thing done and the first thing undone: divide both sides by 2 to get x + 3 = 8, then subtract 3. (You may also expand to 2x + 6 = 16 first — both are correct.)
Always check by substituting: 3 × 5 + 5 = 20 ✔

Applying

Mixed Review & Word Problems

Copy this onto your bound reference: The words-to-algebra translation table.

Word problems are only hard because the equation is hidden. Build it in three moves.

Worked example. Maya buys 4 identical pens and a $3 notebook. She spends $19 altogether. How much is one pen?
  1. Name the unknown. Let p = the cost of one pen, in dollars.
  2. Build the expression. 4 pens cost 4p; add the notebook: 4p + 3.
  3. Set it equal to what you know, then solve. 4p + 3 = 19 → 4p = 16 → p = 4.
  4. Answer in words, with units. One pen costs $4. Check: 4 × 4 + 3 = 19 ✔
Translation table

sum of / more than / increased by+
difference / less than / decreased by−
product of / times / double / triple×
quotient / shared between / half of÷
is / gives / results in / altogether=
Order trap: “5 less than n” is n − 5, not 5 − n. Read it as “start with n, take 5 away”.

The Mistakes That Cost Marks

Every one of these is common, and every one of them is avoidable. If you recognise yourself in the left column, put the right column on your bound reference.

The mistakeWhat is actually true
Says the coefficient of x is 0 or nothingIt is 1. The 1 is invisible but always there — and in −x it is −1.
Writes 3x + 2x = 5x²Add the coefficients only. The letter part never changes: 5x.
Substitutes x = 5 into 3x and writes 35A number written next to a letter means multiply: 3 × 5 = 15.
Works out x² when x = 4 as 8x² means x × x, so it is 16.
Confuses the term number with the term valuen is the position in the pattern, never the number sitting in the pattern.
Solves 3x + 5 = 20 by dividing by 3 firstUndo in reverse order. The +5 was done last, so it comes off first.
Expands 2(x + 3) as 2x + 3The 2 multiplies everything inside: 2x + 6.
Writes “5 less than n” as 5 − nRead it as an instruction: start with n, take 5 away — n − 5.
Never checks the answerSubstitute back into the original equation. It catches most of your own mistakes for free.

Quick Glossary

TermMeaning
Pronumeral / variableA letter standing for a number we do not know yet.
CoefficientThe number multiplying a pronumeral. In 7x it is 7; in x it is 1.
ConstantA term that is just a number, with no letter attached.
TermA chunk of an expression separated by + or − signs.
ExpressionTerms joined by operations, with no equals sign. e.g. 4y − 9
EquationTwo expressions joined by an equals sign. e.g. 4y − 9 = 3
Like termsTerms with exactly the same letter(s) and power, so they can be added.
SubstituteReplace a pronumeral with a given number, then evaluate.
SolveFind the value of the pronumeral that makes an equation true.
SolutionThat value. Check it by substituting it back into the original equation.
Inverse operationThe operation that undoes another: + and −, × and ÷.
LHS / RHSLeft-hand side / right-hand side of the equals sign.
Term number (n)A term's position in a pattern — 1st, 2nd, 3rd — not its value.
Common differenceThe fixed amount a pattern goes up or down by each step.
ExpandMultiply out a bracket, e.g. 3(x + 4) becomes 3x + 12.
